# Library Management System

## Overview
This project is a Flask-based library management system that allows users to manage books, members, and book loans using a relational database.

## Features
- Add, update, and delete books
- Manage library members
- Track book loans
- Dashboard with summary statistics
- Server-side validation

## Technologies Used
- Python
- Flask
- SQLite
- SQLAlchemy
- HTML/CSS
- Bootstrap

## Running the Project

### Create Virtual Environment
python -m venv venv

### Activate Environment
venv\Scripts\activate

### Install Dependencies
pip install -r requirements.txt

### Start Application
python app.py
